# Запись

![](../img/icons_bg/%D0%97%D0%B0%D0%BF%D0%B8%D1%81%D1%8C.png)

## Что делает
Запускает **XYZ Запись** — программу записи экрана со звуком — прямо из Revit. Замечания голосом, короткая инструкция, ролик для коллеги или ИИ-агента — без отдельного поиска ярлыка.

Если программы на компьютере нет, кнопка сама скачивает портативную версию с GitHub ([Budzhak/XYZ-Record](https://github.com/Budzhak/XYZ-Record)) в `%LOCALAPPDATA%\XYZ\Record` и запускает её.

## Как пользоваться
1. Панель «Обмен», кнопка «Запись» — открывается прибор XYZ Записи.
2. **F9** — старт и стоп записи.
3. **Shift+щелчок** по кнопке — открыть папку программы.

## Что умеет XYZ Запись (v19.12)
- Весь экран, одно окно или выбранная область; звук с микрофона, улучшение голоса.
- Показ мыши и клавиш в ролике: мягкая подсветка курсора, вспышки щелчков (левый — красный, правый — синий), нажатые клавиши крупным текстом в выбранном углу. Настройка — меню «Мышь и клавиатура в записи…».
- После записи — «Обрезать»: вырезать лишнее прямо в программе.
- Облики корпуса (палитры) под себя.
